# Event Flow Planner

EVENT PLANNER 

Method of usage

Step1: Login window that will help use in fetching the database and management.

Step2: the main window will consist of current events , new events , fetch event ( something that will help use see the event made by others)

Step3: on clicking on new event , it will open a new page where we can add nodes which will consists of event details like event name , description of the procedure and preferences, concerned parties , details and links of companies or people who will be responsible for that perticular event (like a banquet hall or catering service) and some other ideas from you guys.

Step4: the nodes will be arranged like a Linked list each pointing to the next event and whenever a event is done, we can mark it as done and the background colour of the node will change (like from red to green or something like that).

Step5: we can group the nodes in small groups as well based on smaller details like same day events or events happening simultaneously or events organised by multiple groups/companies.

Step6: a share button to share the event planner with others how are part of the planning (like siblings or parents) and select an option to decide wether they can do any changes to the planner or not.

Step7: Add an approve button so that the creator can know if the person has approved the plan and if he wants any changes he can do it and request the changes to be done (like the pull request option in GitHub)
